v1.2.14 — Live run card on your Lock Screen, watch stability, refreshed home

[Your run, right on the Lock Screen]
• While you run, time, distance and pace show live on the Lock Screen - no need to unlock.
• On devices with Dynamic Island, your distance stays visible at the top of the screen.
• A grass gauge grows one cell for every kilometer.

[Apple Watch stability ⌚]
• Fixed an issue where a run would not start right after the countdown on some devices.
• Location permission is now requested before the run starts, making your first run smoother.

[A lighter home screen]
• Duplicate cards are merged and regrouped: Now → This week → This month → Together → My records.
• All seven charts moved to a dedicated Stats page, one tap away from home.
• Friends, neighborhood and catch-up rankings now live in a single competition hub.

[Run tracking]
• Fixed routes drawing a straight line across GPS signal gaps - applies to past runs too.
• Leaving a run now always saves it (only runs under 50m are discarded).

[Running together]
• Runner discovery now recommends by neighborhood and similar pace, with reasons shown.
• Send a friend request directly from a pacemaker card.
